# 最終実験結果

## Genesis 60秒評価

下位Phase112歩行PPOと上位Phase50の12D追跡・回避PPOを使用。`close_start`、3,000ステップ、20 ms刻み、手動yaw制限なし。

| 指標 | 元の最終評価 | L4再実行 |
|---|---:|---:|
| シミュレーション時間 | 60.00秒 | 60.00秒 |
| 役割交代 | 8回 | 8回 |
| 軌跡データ | 6,000行 | 6,000行 |
| 最終距離 | 0.523 m | 0.523 m |

役割交代ステップ：208、614、1043、1332、1701、2017、2303、2662。

T4での再実行では1,455ステップ（29.1秒）、役割交代4回の時点で `EARLY_STOP_LOW_HEIGHT` による安全停止が発生しました。GPUの違いだけが原因かは未確定です。

## 解釈上の制約

- 役割交代は距離0.80 m以下で行う**ルール制御**です。役割交代自体をPPOが獲得したわけではありません。
- 60秒完走は特定の初期配置・実行条件での結果であり、他条件への一般化を示しません。
- Phase54までの追加学習では評価指標に改善・悪化が混在しました。Phase50を最終60秒評価に採用しています。
- 姿勢情報を含む12D PPOで実測学習を実施しましたが、12D化による安定性改善の因果的な証明は行っていません。
- PyBulletの動画はGenesis記録の描画であり、別の物理実験ではありません。
